M1 test cases

The 66 cases M1 Identity is tested against. They cover ABHA creation by Aadhaar OTP, Aadhaar biometric, demographic authentication and driving licence or PAN, then verification, profile update, one ABHA per patient record, and sharing a profile by QR code. Each row keeps the case id the functional testing report uses, and links every API the case calls. How to read a case explains the columns and markings.

Every call needs a gateway session first: POST /api/hiecm/gateway/v3/sessions.

API paths in the tables below start with /abha/api/v3 unless shown in full. The prefix is left off each row to keep the table readable.

An AI coding assistant can walk these cases against your own system with the M1 Identity skill.
