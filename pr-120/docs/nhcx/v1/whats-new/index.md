# What's new in NHCX

Changes to the NHCX documentation that affect what you build, newest first. Each entry links to what you can now read, run or consume. Changes to other gateways are on the [site-wide What's new](/docs/pr-120/docs/whats-new).

## What gets an entry

An entry has to change what you build or what you must go back and fix. Six kinds qualify:

- new coverage
- a correction
- a republished source
- an operation added or withdrawn
- a new artefact you can consume
- a procedure documented for the first time

Page layout, navigation and wording changes do not get an entry.
