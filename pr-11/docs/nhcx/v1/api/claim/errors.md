# Claim errors

Codes any exchange call can meet are recorded once, in the [Other](/docs/pr-11/docs/nhcx/v1/api/other) specification: the gateway's NHCX- codes, the standard payer codes, and the reference payer's structure and transport codes. The reference payer's other codes sit with the exchange they reject: coverage eligibility, preauthorisation, claim and insurance plan. [Reading error codes](/docs/pr-11/docs/nhcx/v1/reference/error-code-guide) explains the code spaces.
