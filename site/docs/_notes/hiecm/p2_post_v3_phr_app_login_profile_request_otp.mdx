## Link ABHA number via AADHAAR-Request OTP {/* #p1-link-abha-number-via-aadhaar-request-otp */}

Starts linking an [ABHA number](/docs/hiecm/v3/getting-started/glossary#abha-number) to the [ABHA address](/docs/hiecm/v3/getting-started/glossary#abha-address) signed in, with a one time password ([OTP](/docs/hiecm/v3/getting-started/glossary#otp)) sent through Aadhaar. Send `scope` `abha-login` and `aadhaar-verify`, `loginHint` `abha-number`, the ABHA number encrypted as `loginId`, and `otpSystem` `aadhaar`.

<AgentOnly>
**Before you start.** A signed in person, whose user token goes in `X-token`, and their ABHA number encrypted with the public certificate.

**How you know it worked.** The response carries a `txnId` and a `message` naming the masked number the code went to. Verify the code with the same `scope`.

**When it goes wrong.** `ABDM-1006` names the field that failed, such as `Invalid ABHA Number` or `Invalid Otp System`.
</AgentOnly>

## Link ABHA number via Mobile-Request OTP {/* #p1-link-abha-number-via-mobile-request-otp */}

Starts linking an [ABHA number](/docs/hiecm/v3/getting-started/glossary#abha-number) to the [ABHA address](/docs/hiecm/v3/getting-started/glossary#abha-address) signed in. A one time password ([OTP](/docs/hiecm/v3/getting-started/glossary#otp)) goes to the mobile number registered with the ABHA number. Send `scope` `abha-login` and `mobile-verify`, `loginHint` `abha-number`, the ABHA number encrypted as `loginId`, and `otpSystem` `abdm`.

<AgentOnly>
**Before you start.** A signed in person, whose user token goes in `X-token`, and their ABHA number encrypted with the public certificate.

**How you know it worked.** The response carries a `txnId` and a `message` naming the masked number the code went to. Verify the code with the same `scope`.

**When it goes wrong.** `ABDM-1006` names the field that failed, such as `Invalid ABHA Number` or `Invalid Scope`.
</AgentOnly>

## Update the mobile number, request the OTP {/* #p1-update-mobile-request-otp */}

Starts changing the mobile number on the [ABHA address](/docs/hiecm/v3/getting-started/glossary#abha-address) signed in. A one time password ([OTP](/docs/hiecm/v3/getting-started/glossary#otp)) goes to the new number. Once it is verified, the new number replaces the old one. Send `scope` `abha-address-profile` and `mobile-verify`, `loginHint` `mobile-number`, the new number encrypted as `loginId`, and `otpSystem` `abdm`.

<AgentOnly>
**Before you start.** A signed in person, whose user token goes in `X-token`, and the new mobile number encrypted with the public certificate.

**How you know it worked.** The response carries a `txnId` and a `message` naming the masked number the code went to.

**When it goes wrong.** `ABDM-1006` with `Invalid mobile number` means the number could not be read.
</AgentOnly>
