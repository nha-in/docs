## Notify the gateway that a data transfer finished {/* #m2-hip-data-flow-notify */}

After you push the encrypted records to the `dataPushUrl`, call this to report the transfer. Set `notifier.type` to `HIP`. Set `sessionStatus` to `TRANSFERRED` or `FAILED`. Give each care context a `hiStatus` of `DELIVERED` or `ERRORED`.

<AgentOnly>
**Before you start.** A gateway session token, and the `transactionId` and consent artefact id of the request. Send the `REQUEST-ID`, `TIMESTAMP` and `X-CM-ID` headers.

**What happens.** `doneAt` is a UTC date time. `hipId` is your HIP id. The call returns 202 Accepted.

**When it goes wrong.** `ABDM-1031` (Invalid request): check the body. A `hiStatus` of `OK` is the HIU's value, not the HIP's. `ABDM-2402` (Invalid Timestamp): check `TIMESTAMP` against your clock. `ABDM-2404` (Invalid Request Id): send a fresh UUID in `REQUEST-ID`. `ABDM-2500` (Authorization header is missing): send the session token. `ABDM-9999` (Unknown exception) gives no cause.
</AgentOnly>
