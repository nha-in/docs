## Find a bridge service by its service id {/* #gateway-get-bridge-service-by-id */}

Returns one service registered on your [bridge](/docs/hiecm/v3/getting-started/glossary#bridge), looked up by the service id in the path. The response names the service, the bridge it belongs to, whether it is active, and which roles it holds through `isHip`, `isHiu`, `isHealthLocker` and `isPhr`. Use it to check that a service holds the role a journey needs, for example `isHip` before you link records.

<AgentOnly>
**Before you start.** The service id as registered. Send the access token as `Authorization: Bearer <gateway token>`, with `REQUEST-ID`, `TIMESTAMP` and `X-CM-ID`.

**How you know it worked.** A 200 whose `serviceId` matches the id you asked for, with `active` true and the role flag you need set to true.

**When it goes wrong.** A 204 with `ABDM-1001` means no service is registered under that id. A 401 with `900901` means the access token is missing or expired.
</AgentOnly>
