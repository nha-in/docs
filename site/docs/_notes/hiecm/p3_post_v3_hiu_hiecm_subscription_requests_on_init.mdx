## Subscription request result callback {/* #p3-user-subscription-request-initiate-call-back */}

ABDM posts the result of your subscription request here. On success, `subscriptionRequest.id` is the id of the request now waiting for the person's decision.

<AgentOnly>
**What happens.** `response.requestId` is the request id of your init call. Store `subscriptionRequest.id`: the approve or deny notification quotes it.

**How you know it worked.** `subscriptionRequest.id` is present. Answer with `200`.

**When it goes wrong.** An `error` object means no request was created. Read the error `message`, fix the init body and send it again.
</AgentOnly>
