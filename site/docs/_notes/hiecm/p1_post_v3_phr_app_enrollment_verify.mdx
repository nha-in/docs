## Verify the registration OTP {/* #p1-enrollment-verify-otp */}

Verifies the one time password ([OTP](/docs/hiecm/v3/getting-started/glossary#otp)) with the same `scope` the request used. The response is where you learn whether this person already holds [ABHA addresses](/docs/hiecm/v3/getting-started/glossary#abha-address): `users` lists them. Show that list before you offer to create another.

<AgentOnly>
**Before you start.** The `txnId` from the request OTP call, and the code the person typed, encrypted as `otpValue`. `authMethods` is `otp`.

**How you know it worked.** `authResult` is `success` and `message` is `OTP Verified Successfully`. `users` lists the addresses already linked, and `tokens` carries the session.

**When it goes wrong.** `ABDM-9999` with `Invalid Transaction Id` means the `txnId` is wrong or spent. `ABDM-1006` names the field that failed: `Invalid OTP Request`, `Invalid Scope` or `Invalid Auth Methods`.
</AgentOnly>
