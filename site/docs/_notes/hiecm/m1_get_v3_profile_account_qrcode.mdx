## Get the ABHA QR code {/* #m1-profile-get-qr-code */}

Returns a QR code for the signed in person's [ABHA](/docs/hiecm/v3/getting-started/glossary#abha) profile. A facility can scan it to read the person's details without typing them. Send the person's `X-token`.

<AgentOnly>
**When it goes wrong.** A 400 with `Invalid X-token` means the token is missing, wrong or expired. A 401 with `900901` means the access token is missing or expired.
</AgentOnly>
