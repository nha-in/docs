# Getting started

Welcome to the ABDM Developer Portal. This site documents the HIE-CM gateway
(ABDM V3) so that a first-day developer can follow it.

## What you will find here

- **Guides** in this section: concepts, flows, sandbox setup, and
  troubleshooting, written from the catalogue of typed atoms.
- **[HIE-CM API reference](/reference/hiecm)**: the interactive OpenAPI
  reference rendered with Scalar.

## Status

The catalogue is being built. Pages that have not been verified against the
ABDM sandbox say so explicitly. An unverified page that admits it is useful;
a confident wrong page is harmful.
