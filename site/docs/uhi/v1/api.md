# UHI API reference

No OpenAPI specification is published here for UHI yet. The message shapes on the service pages are transcribed from NHA's onboarding documents, and each page names its document.

- [Network and protocol](/docs/uhi/v1/network-and-protocol): the search, select, init and confirm pattern every UHI service shares, and the roles on either side of it.
- [Onboarding](/docs/uhi/v1/onboarding): registration, the signing keys and the callback URL your participant registers.
- The service pages: the fields each service adds on top of the shared pattern.
