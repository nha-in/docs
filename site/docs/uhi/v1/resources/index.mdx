# Developer resources

No test scenarios, FHIR profiles or error code lists are published for UHI yet. What exists today is in the guides:

- [Network and protocol](/docs/uhi/v1/concepts/network-and-protocol): the search, select, init and confirm pattern every UHI service shares.
- [Onboarding](/docs/uhi/v1/getting-started/onboarding): registration, the signing keys and the callback URL your participant registers.
- [UHI API reference](/docs/uhi/v1/api): where the message shapes for each service are written down.
