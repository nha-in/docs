# Ambulance Booking

Send a patient's details to the chosen ambulance provider and get a quote and terms back. Phase 1 covers discovery and the quote. The [EUA](/docs/uhi/v1/getting-started/glossary#eua) sends `init` directly to the [HSPA](/docs/uhi/v1/getting-started/glossary#hspa), and the HSPA answers with `on_init`.

## What it holds

| Call | Served by | What it does |
| --- | --- | --- |
| `POST /init` | HSPA | Takes the patient's details for a quote |
| `POST /on_init` | EUA | Receives the quote and terms |

Every Ambulance Booking call uses `context.domain` `nic2008:86909`.

## Journeys

| Journey | What it covers |
| --- | --- |
| [Discovery](/docs/uhi/v1/api/ambulance/endpoints/uhi-ambulance-discovery/01-uhi-network-gateway-search) | The Gateway search for ambulances near a pickup location |
| [Order](/docs/uhi/v1/api/ambulance/endpoints/uhi-ambulance-order/01-uhi-ambulance-init) | `init` and `on_init`, direct between EUA and HSPA |

Sign every call first. See [Signing](/docs/uhi/v1/concepts/signing).
