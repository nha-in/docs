# Get started

Connect your app to the Unified Health Interface
([UHI](/docs/uhi/v1/getting-started/glossary#uhi)) network.

UHI is an open network under the Ayushman Bharat Digital Mission
([ABDM](/docs/uhi/v1/getting-started/glossary#abdm)). A patient app built once
can discover health services from every compliant provider platform, and book
some of them. Every exchange is asynchronous: you send a signed request, get an
`ACK` at once, and receive the answer later on your own callback URL.

You build one of two sides. A patient-facing app is an
[EUA](/docs/uhi/v1/getting-started/glossary#eua). A provider system that
answers searches is an [HSPA](/docs/uhi/v1/getting-started/glossary#hspa).
[Introduction to UHI](/docs/uhi/v1) sets out the parties, the six live services
and how to choose.

An EUA must complete [Milestone 2](/docs/hiecm/v3/milestones/m2) on
[HIE-CM](/docs/uhi/v1/getting-started/glossary#hie-cm) before it can be
onboarded onto any UHI service.
