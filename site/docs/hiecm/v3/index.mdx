# Get started

Connect your application to India's health data network.

## Start here: build with AI

Install the plugin and your coding agent gets every ABDM skill, plus live retrieval over the Docs MCP server.

```bash
claude plugin marketplace add eka-care/abdm-docs && claude plugin install abdm@abdm-portal
```

Using Cursor, Codex or another agent? [Build with AI](/docs/hiecm/v3/getting-started/build-with-ai) has the one line to paste.
