# M2 UI test cases

The 13 cases [M2 Health Information Provider](/docs/hiecm/v3/milestones/m2) is tested against. They cover creating health records, linking care contexts to an ABHA address whether your facility or the patient starts it, and sharing records when a consent arrives.
Each row keeps the case id the functional testing report uses, and links every API the case calls.
[How to read a case](/docs/hiecm/v3/resources/test-cases#how-to-read-a-case) explains the columns and markings.

An AI coding assistant can walk these cases against your own system with the [M2 skill](/docs/hiecm/v3/milestones/m2#build-m2-with-an-ai-coding-assistant).
