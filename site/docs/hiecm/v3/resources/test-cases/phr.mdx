# PHR application UI test cases

The 200 cases [PHR application](/docs/hiecm/v3/milestones/p1) is tested against. They cover registering and logging in with an ABHA address, linking and sharing health records, consents and subscriptions, and the health locker.
The sheet numbers its rows but gives them no ids, so each case here has an id built the way the HMIS ids are, from its PHR milestone and row: row P1 3.2 is `PHR_ADDR_302`, and P2, P3 and P4 are `PHR_APP_`, `PHR_HIU_` and `PHR_LOCKER_`. Quote the id when you report a result.
[How to read a case](/docs/hiecm/v3/resources/test-cases#how-to-read-a-case) explains the columns and markings.

An AI coding assistant can walk these cases against your own system with the [Build with AI](/docs/hiecm/v3/getting-started/build-with-ai) tools.
