# M3 test cases

The 16 cases [M3 Health Information User](/docs/hiecm/v3/milestones/m3) is tested against. They cover raising a consent request, receiving the patient's decision, and fetching and showing the records the consent covers.
Each row keeps the case id the functional testing report uses, and links every API the case calls.
[How to read a case](/docs/hiecm/v3/resources/test-cases#how-to-read-a-case) explains the columns and markings.

An AI coding assistant can walk these cases against your own system with the [M3 skill](/docs/hiecm/v3/milestones/m3#build-m3-with-an-ai-coding-assistant).
