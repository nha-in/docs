# M1 ABHA identity

Create an ABHA, authenticate a holder, and read or update the profile, QR code and linked mobile number.

## Base URLs

| Environment | Base URL |
|---|---|
| Sandbox | `https://abhasbx.abdm.gov.in/abha/api/v3/` |
| Production | `https://abha.abdm.gov.in/api/abha/v3/` |

Login by Aadhaar number using fingerprint or IRIS uses v3.1 instead: `https://abhasbx.abdm.gov.in/abha/api/v3.1/` in sandbox. No production v3.1 URL is published.
