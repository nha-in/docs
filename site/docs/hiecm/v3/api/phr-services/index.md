# PHR application services

**These are not a certification milestone.** Nothing here is required to certify as a [PHR](/docs/hiecm/v3/getting-started/glossary#phr).

They are application features that happen to sit in NHA's reference PHR collection: teleconsultation, nearby facility search, ambulance booking, blood bank search, scan and pay, PMJAY facility discovery and [NHCX](/docs/nhcx/v1) coverage lookups.

They are documented so the collection is not half ingested, and kept out of P1 to P3 so nothing implies a PHR must build them.

## Where this comes from

Derived from NHA's Aarogya Setu collection. Nothing here has been run against the sandbox from this repository.

The full operation list is in the [PHR application services API reference](/reference/hiecm-phr-services).
