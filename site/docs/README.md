# Docs tree

Every page of the portal renders from this tree: one folder per platform
(gateway), one folder per version under it, and section folders below that.
Where you put a file is where it renders. `README.md` files like this one are
notes for contributors and are never rendered as pages.

See [CONTRIBUTING.md](../../CONTRIBUTING.md) for the full rules, ordering with
`sidebar_position`, and how the API reference is generated from OpenAPI YAML.
