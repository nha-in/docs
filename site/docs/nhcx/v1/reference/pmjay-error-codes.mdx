# PMJAY error codes

Every error code a PMJAY integration can meet, in one table. `NHCX-` codes come from the exchange, `PAYR-` codes from the PMJAY payer, and `ERR-PYR-` codes have been seen only in live traffic. Search by code, by a phrase from the message, or by the path you called. Filter by the part of the claim the code belongs to.

Eighteen codes from `PAYR-1001` to `PAYR-1020` mean different things on the standard payer sheet and on the PMJAY payer's, so read a code with the message beside it. [Reading error codes](/docs/nhcx/v1/reference/error-code-guide) explains the code spaces and what to do about each collision.
