# PHR application test cases

The 200 cases [PHR application](/docs/main/docs/hiecm/v3/milestones/p1) is tested against. They cover registering and logging in with an ABHA address, linking and sharing health records, consents and subscriptions, and the health locker. The sheet numbers its rows but gives them no ids, so each case here is named by its PHR milestone and row, such as `P1 1.1`. Quote that name when you report a result. [How to read a case](/docs/main/docs/hiecm/v3/resources/test-cases#how-to-read-a-case) explains the columns and markings.

An AI coding assistant can walk these cases against your own system with the [Build with AI](/docs/main/docs/hiecm/v3/getting-started/build-with-ai) tools.
