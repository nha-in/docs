# Scan and Register

Receive the profile a patient shares by scanning the counter QR code, and hand back a queue token.

## Postman collection

1 requests in the order you build them, and a sandbox environment to fill in.

[Collection](/docs/main/postman/hiecm-scan-and-register.postman_collection.json)[Environment](/docs/main/postman/hiecm-sandbox.postman_environment.json)

`https://nha-in.github.io/docs/main/postman/hiecm-scan-and-register.postman_collection.json`

Postman, Insomnia, Hoppscotch and Bruno take this through Import, as a link or as the downloaded file.
