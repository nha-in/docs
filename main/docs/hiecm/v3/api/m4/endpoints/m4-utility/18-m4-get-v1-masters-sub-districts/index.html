Get all sub districts

GET/apis/v1/masters/sub-districts

Authorizations

Authorizationbearer tokenRequired

M4 declares bearer authentication. The HPID calls publish POST /getManagementToken.

Responses

200

OK

404

Not Found

curl --request GET \
  --url https://apihspsbx.abdm.gov.in/v4/int/apis/v1/masters/sub-districts \
  --header 'Authorization: Bearer <ACCESS_TOKEN_FROM_SESSIONS_CALL>'
