# P4 Locker

Set up a health locker and list the lockers and requests on an ABHA address.

## Postman collection

5 requests in the order you build them, and a sandbox environment to fill in.

[Collection](/docs/main/postman/hiecm-p4.postman_collection.json)[Environment](/docs/main/postman/hiecm-sandbox.postman_environment.json)

`https://nha-in.github.io/docs/main/postman/hiecm-p4.postman_collection.json`

Postman, Insomnia, Hoppscotch and Bruno take this through Import, as a link or as the downloaded file.
