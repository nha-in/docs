# M2 Health Information Provider: Create and link records

Link care contexts to a patient's ABHA address, answer discovery requests, and share encrypted health records with consent.

## Postman collection

10 requests in the order you build them, and a sandbox environment to fill in.

[Collection](/docs/main/postman/hiecm-m2.postman_collection.json)[Environment](/docs/main/postman/hiecm-sandbox.postman_environment.json)

`https://nha-in.github.io/docs/main/postman/hiecm-m2.postman_collection.json`

Postman, Insomnia, Hoppscotch and Bruno take this through Import, as a link or as the downloaded file.
