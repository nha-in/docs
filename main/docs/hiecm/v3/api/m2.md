# M2 linking and sharing

Link care contexts to a patient's ABHA address, answer discovery requests, and share encrypted health records with consent.

## Base URLs

| Environment | Base URL                   |
| ----------- | -------------------------- |
| Sandbox     | `https://dev.abdm.gov.in`  |
| Production  | `https://apis.abdm.gov.in` |

The full operation list is in the [M2 API reference](/docs/main/reference/hiecm-m2).

New to this? Start with [M2 Health Information Provider](/docs/main/docs/hiecm/v3/milestones/m2).
