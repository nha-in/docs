Other errors

Codes any exchange call can meet are recorded once, in the Other specification: the gateway's NHCX- codes, the standard payer codes, and the reference payer's structure and transport codes. The reference payer's other codes sit with the exchange they reject: coverage eligibility, preauthorisation, claim and insurance plan. Reading error codes explains the code spaces.

18 codes from PAYR-1003 to PAYR-1020 mean one thing on the standard payer sheet and another on the reference payer's sheet. Read the code together with its message.

Observed codes​

Observed live codes, ERR-PYR-. Sent by the PMJAY reference implementation, on none of its published sheets; they arrive inside the sealed response.

CodeMessageWhat to do
ERR-PYR-CLM-007No prior preauthorization or claim record found for case numberOn none of the seven sheets. The SHA HP sandbox sent it for a claim raised under a number of its own rather than the preauthorisation's.

Code ranges​

RangeWhat it coversExamples
NHCX-1xxxThe exchange, on the envelope. The message never reached the payer.NHCX-1001, NHCX-1002
PAYR-10xxTransport and bundle structure. An element, id, sequence or type is missing. Not a value problem.PAYR-1001, PAYR-1002
PAYR-11xxCoverage eligibility. The policy, the beneficiary or the hospital configuration.PAYR-1101, PAYR-1102
PAYR-12xxPreauthorisation. Codes, amounts, dates, sequencing and scheme rules.PAYR-1201, PAYR-1202
PAYR-13xxClaim. The same, against the approved preauthorisation.PAYR-1301, PAYR-1302
PAYR-14xxInsurance plan, and the scheme's outer rules. Empanelment, policy association, plan configuration.PAYR-1401, PAYR-1402

Every code above is recorded in the specification that owns it. The aggregated list across modules is at error codes.
