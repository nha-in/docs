# M1 UI test cases

The 100 cases [M1 Identity](/docs/pr-135/docs/hiecm/v3/milestones/m1) is tested against. They cover ABHA creation by Aadhaar OTP, face authentication, Aadhaar biometric, demographic authentication and driving licence, then login by ABHA number, ABHA address, mobile and Aadhaar, profile update, one ABHA per patient record, and sharing a profile by QR code. Each row keeps the case id the functional testing report uses, and links every API the case calls. [How to read a case](/docs/pr-135/docs/hiecm/v3/resources/test-cases#how-to-read-a-case) explains the columns and markings.

An AI coding assistant can walk these cases against your own system with the [M1 Identity skill](/docs/pr-135/docs/hiecm/v3/milestones/m1#build-m1-with-an-ai-coding-assistant).
