# P3 Subscription

Read, approve, deny, enable, disable and update the patient's subscriptions and subscription requests, and the subscription request and notifications they answer.

## Postman collection

11 requests in the order you build them, and a sandbox environment to fill in.

[Collection](/docs/pr-44/postman/hiecm-p3.postman_collection.json)[Environment](/docs/pr-44/postman/hiecm-sandbox.postman_environment.json)

`https://nha-in.github.io/docs/pr-44/postman/hiecm-p3.postman_collection.json`

Postman, Insomnia, Hoppscotch and Bruno take this through Import, as a link or as the downloaded file.
