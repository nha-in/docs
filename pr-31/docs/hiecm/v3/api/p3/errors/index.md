# P3 Subscription errors

Seeing a symptom rather than a code? Start at [Troubleshooting](/docs/pr-31/docs/hiecm/v3/troubleshooting/).

The P3 Subscription specification records no error code yet. That is a gap in the specification, not a promise that this module cannot fail.

Every code above is recorded in the specification that owns it. The aggregated list across modules is at [error codes](/docs/pr-31/docs/hiecm/v3/reference/error-codes).
