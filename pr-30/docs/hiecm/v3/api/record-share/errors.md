# Patient scan and record share errors

Seeing a symptom rather than a code? Start at [Troubleshooting](/docs/pr-30/docs/hiecm/v3/troubleshooting/).

The Patient scan and record share specification records no error code yet. That is a gap in the specification, not a promise that this module cannot fail.

Every code above is recorded in the specification that owns it or in NHA's list for the module. The aggregated list across modules is at [error codes](/docs/pr-30/docs/hiecm/v3/reference/error-codes).
