# PM-JAY HEM, the system that knows which hospitals are empanelled

## In plain words

PM-JAY Hospital Empanelment Management: the system that knows which hospitals are empanelled under PM-JAY today. The PM-JAY HEM [HSPA](/docs/uhi/v1/getting-started/glossary#hspa) searches it live. See [PM-JAY HEM Hospital Discovery](/docs/uhi/v1/services/pmjay-hem).
