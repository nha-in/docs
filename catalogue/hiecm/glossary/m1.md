# M1 Identity: Create and verify ABHA

## In plain words

ABDM Milestone 1, Create and verify ABHA, implemented through the HIE-CM
gateway: creating an
[ABHA number](abha-number.md), logging a person in, reading and updating
their profile, downloading the ABHA card, and the
[gateway](gateway.md) session and token calls that everything else
depends on. Most of these APIs are mandatory for both private and
government integrators, with Aadhaar demographic authentication the
exception: mandatory for government integrators, not required for
private ones. See [M1](/docs/hiecm/v3/api/m1).

## Before you start

Nothing. A glossary entry assumes no prior reading.

## What happens

Nothing happens here. This entry defines a term, it does not describe a call.

## How you know it worked

You have understood this when you can say whether your system needs M1 without reading the endpoint list.

## When it goes wrong

Building M1 because it is first. A system that never creates or reads an
ABHA does not need it.
