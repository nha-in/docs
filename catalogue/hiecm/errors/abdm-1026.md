# ABDM-1026, the link token is not valid

## In plain words

Linking a [care context](/docs/hiecm/v3/getting-started/glossary#care-context) needs a [link token](/docs/hiecm/v3/getting-started/glossary#link-token), and the one you sent is not usable. The message is "Invalid Link Token". A mismatch has its own code:

- `ABDM-1038`, "ABHA address and Link token mismatch"
- `ABDM-1062`, "ABHA number mismatch with Link token"
- `ABDM-1063`, "HIP Id mismatch with Link token"

## When it goes wrong

A link token is valid for six months, so check it before you use it. If it has expired, or was issued for another patient or facility, generate a new one through the [link token call](/docs/hiecm/v3/api/m2/endpoints/m2-abdm-link-token-hip/01-m2-post-v3-token-generate-token). Do not retry with the old token.
