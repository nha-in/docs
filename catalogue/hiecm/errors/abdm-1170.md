# ABDM-1170, the address is malformed or does not exist here

## In plain words

The ABHA address you sent is not one ABDM will accept.

The environment suffix is the usual reason, and it is the one people
chase longest because the address looks correct.

## Before you start

You have received this code in a response body. Nothing else is assumed.

## What happens

NHA's own wording for this code is "Invalid ABHA address".


  Sandbox addresses end `@sbx` and production addresses end `@abdm`. An
  address from one environment does not exist in the other.

  It also appears when the address breaks NHA's policy: fewer than four
  characters, a leading digit, or a leading or trailing dot.

## How you know it worked

The call is accepted and, in a linking flow, the confirming callback names the same address you sent.

## When it goes wrong

Check the suffix matches the environment you are calling.

If it does, check the address against NHA's policy, then confirm the
account exists by looking it up before linking against it.
