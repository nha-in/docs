# 900900, authentication failed without a reason

## In plain words

The [ABHA](/docs/hiecm/v3/getting-started/glossary#abha) service returns `900900` with HTTP 500 and the message "Unclassified Authentication Failure". The `description` field names the API that refused the call. Authentication failed, and the response does not say which credential was at fault.

## What happens

The M1 examples return it where the access token is not valid. Many M1 calls take two tokens, the access token in `Authorization` and the person's token in `X-token`, so either can be the cause.

## When it goes wrong

Check both tokens. `Authorization` must carry a current access token from the session call. `X-token`, where the call takes one, must be the token issued when this person logged in. If both are current, confirm your client is allowed to call this API.
