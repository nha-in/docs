## In plain words

ABDM-1094 is an entitlement failure, HTTP 401. Your client id is not
allowed to do what it just tried. It carries two messages:
"Access to this feature is restricted. Please contact NHA to enable it"
means the endpoint itself is off limits for your client; "Invalid
Benefit Name" means the BENEFIT_NAME header you sent does not match a
benefit programme registered against your client. A third, "Invalid
benefit role", is the same entitlement refusal on a benefit call.

This code is not about the `X-token` header. Profile calls need
`X-token: Bearer <token>`, and a bare token is refused with
`400 {"message":"Invalid X-token"}`, not with ABDM-1094. An earlier
reading that the `Bearer` prefix caused ABDM-1094 came from a call made
with a transfer token, which fails either way. See
[verify a login OTP](hiecm.endpoint.m1-login-verify) for which token is
final.

## Before you start

Know which integrator category you are. Every recorded case of the
restricted message is on a benefit programme or insurance call, which
are government integrator only.

## What happens

Conditions that produce this error: calling a benefit or insurance
endpoint without the entitlement, or sending a BENEFIT_NAME value that
is not registered for you. The body shape varies: the same code appears
both wrapped in an `error` object and as a top level `code` field with a
timestamp. Read `error.code` first and fall back to the top level
`code`. See [error body shapes](hiecm.concept.error-body-shapes).

## How you know it worked

The original call returns a non 401 response. For the benefit name case,
the registered name is used exactly, such as `healthid api`.

## When it goes wrong

Retrying does not help; entitlement is configuration, not a transient
state. Restricted message: stop calling the endpoint, or ask NHA to
enable the entitlement. Invalid benefit name: use the exact name you were
given at onboarding. If the failing call is a profile read and the body
says `Invalid X-token`, the fix is the `Bearer` prefix, not entitlement.
