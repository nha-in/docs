## In plain words

The HPR token is not the gateway access token. It represents the
professional rather than your client, and it has a life of its own that
ends earlier than the work sometimes takes.

## Before you start

Know which token each call needs. The gateway access token goes in
`Authorization`. The HPR token goes in the payload for register
professional, and in a header for the facility create calls.

## What happens

Conditions that produce this error: a long gap between creating the
HPID and registering the profile, a token cached from an earlier
session, or a document upload run hours after the registration.

## How you know it worked

A freshly obtained HPR token is accepted and the call that failed
succeeds unchanged.

## When it goes wrong

Get a new HPR token, by password, mobile OTP or Aadhaar OTP, and repeat
the call. Do not confuse this with a rejected gateway access token,
which fails differently and is refreshed differently.
