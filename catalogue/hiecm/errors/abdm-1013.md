# ABDM-1013, the fourteen digit number is wrong or wrongly formatted

## In plain words

The ABHA number you sent is not one ABDM recognises.

Most often this is formatting rather than a wrong person.

## Before you start

You have received this code in a response body. Nothing else is assumed.

## What happens

NHA's own wording for this code is "Invalid ABHA Number".


  NHA writes ABHA numbers in the hyphenated form, `91-1234-5678-9012`.
  Sending the digits unhyphenated, or hyphenated differently, produces
  this.

  It also appears when an ABHA address has been sent where a number was
  expected, which is the most common version of the mistake.

## How you know it worked

The call returns the account you expected, and the number in the response matches the one you sent.

## When it goes wrong

Send the number in NHA's hyphenated form, and confirm you are sending a
number rather than an address.

If both look right, the account may not exist in this environment. A
sandbox account does not exist in production.
