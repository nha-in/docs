# ABDM-9999, ABDM is failing and not saying why

## In plain words

A catch-all. Something failed inside ABDM and it is not telling you what.

Nothing about your request is necessarily wrong.

## Before you start

You have received this code in a response body. Nothing else is assumed.

## What happens

NHA's own wording for this code is "Cannot process the request at the moment".


  It appears during ABDM outages and under load, and it is not specific to
  any one call.

  NHA publishes several more specific unavailability codes, including
  `ABDM-1019` and `ABDM-1024` for dependent services, `ABDM-1028` for the
  HIP and `ABDM-1033` for the HIU. This is what you get when none of them
  applies.

## How you know it worked

The same request, unchanged, succeeds later. That is the test: if changing nothing fixes it, it was never yours.

## When it goes wrong

Retry with exponential backoff, and stop after a bounded number of
attempts so a retry loop does not turn into a rate limit block.

If it persists across hours, raise it on the NHA dev forum with your
`REQUEST-ID` and `TIMESTAMP`. Those are what makes a report traceable.
