## In plain words

Discovery returned a care context that the person's account already
holds. Linking it again would create a duplicate, so it is refused.

## Before you start

Hold your own record of what is linked, and filter discovery results
against it. The P2 rule is explicit: never show a care context that is
already linked.

## What happens

Conditions that produce this error: discovery results shown unfiltered,
a repeat of a link that already succeeded, or two devices linking the
same context at once.

## How you know it worked

The care context is present on the person's account, which was the
outcome the link was for.

## When it goes wrong

Treat it as done rather than as a failure. Filter it out of the list and
show the specified message when everything discovered is already linked.
