# ABDM-1064, a repeated request id, or a missing body

## In plain words

One code, two messages:

- "request with this request id already exists": you sent a request id that was already used.
- "Request body was missing": the call needs a JSON body and none arrived.

`ABDM-1067`, "Request body not required", is the opposite case: a body arrived where none is wanted.

## What happens

A request id hardcoded during testing works once and fails afterwards. A missing body usually comes from a client that sends a POST without one, a missing `Content-Type`, or a proxy that strips the body.

## When it goes wrong

Generate a fresh UUID for every request, retries included. Send the JSON body the operation documents, with a `Content-Type` of `application/json`. If your client looks right, log the request as it leaves your process, which is where a proxy shows up.
