# ABDM-1064, you sent no body where one was required

## In plain words

The call needs a JSON body and none arrived.

It is usually a client configuration problem rather than a missing field.

## Before you start

You have received this code in a response body. Nothing else is assumed.

## What happens

NHA's own wording for this code is "Request body was missing".


  A GET-shaped client sending a POST, a missing `Content-Type`, or a proxy
  stripping the body all produce this.

  NHA also publishes the opposite, `ABDM-1067`, for sending a body where
  none is wanted.

## How you know it worked

The call returns its normal response for the operation you were making.

## When it goes wrong

Send the JSON body the operation documents, with
`Content-Type: application/json`.

If your client looks correct, log the outgoing request as it leaves your
process rather than as you constructed it. That is where proxies show up.
