# ABDM-1040, the HIU id is not recognised

## In plain words

ABDM does not recognise the [Health Information User](/docs/hiecm/v3/getting-started/glossary#hiu) (HIU) id on this request. The message is "Invalid HIU ID". Like the [HIP](/docs/hiecm/v3/getting-started/glossary#hip) case, this is a registration problem, so retrying does not change it.

## When it goes wrong

Confirm the entity is registered in the HIU role and that `X-HIU-ID` carries the HIU id, not the HIP id. If you hold both ids, keep them in separate configuration values so they cannot be swapped.
