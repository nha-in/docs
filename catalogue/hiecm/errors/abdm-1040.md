# ABDM-1040, your requester identity is not recognised

## In plain words

ABDM does not recognise the HIU id on this consent request.

Like the HIP version, this is a registration problem.

## Before you start

You have received this code in a response body. Nothing else is assumed.

## What happens

NHA's own wording for this code is "Invalid HIU ID".


  The requesting entity is not registered as an HIU, or the id is from
  another environment.

  Products that are both a HIP and an HIU sometimes send the HIP id here,
  which produces this.

## How you know it worked

The consent request is accepted and the on-init callback arrives with a consent request id.

## When it goes wrong

Confirm the entity is registered in the HIU role and that you are sending
the HIU id rather than the HIP id.

If your product holds both, keep them in separate configuration values so
they cannot be swapped.
