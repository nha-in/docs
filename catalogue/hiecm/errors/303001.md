# 303001, the gateway suspended the endpoint

## In plain words

The gateway returns HTTP 500 with `303001` and a message beginning "Runtime Error", naming the address endpoint as suspended. It follows a run of timeouts on the same call: the gateway stops forwarding to the backend for a while. It is not a problem in your request, and the same request succeeds once the endpoint is back.

## What happens

The code comes from the gateway, not from an ABDM service, so it has no `ABDM-` prefix. It arrives after several timeouts or 504s on one call.

## How you know it worked

The same request, unchanged, succeeds after a pause.

## When it goes wrong

Back off rather than retry at once, or the suspension lasts longer. If the timeouts that preceded it were on `POST /api/hiecm/hip/v3/link/carecontext`, check that each patient entry names its type in `hiType`: a misnamed field gets no answer, and the timeouts lead here.
