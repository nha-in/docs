# ABDM-1062, ABHA number mismatch, or consent not granted

## In plain words

One code, two messages, so read the message as well as the code:

- "ABHA number mismatch with Link token": in linking, the [ABHA number](/docs/hiecm/v3/getting-started/glossary#abha-number) in your request is not the one the link token was issued for.
- "Consent Not granted": the patient has not granted the consent you are acting on.

`ABDM-1061` and `ABDM-1063` also carry two messages each.

## When it goes wrong

Linking: generate a link token for this patient and link with the ABHA number it was issued for. Consent: check the consent's status before you request data. A denied or expired consent does not start working on retry.
