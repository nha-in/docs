# HPID, healthcare professional identifier

## In plain words

Healthcare Professional ID: a 14 digit number issued to a healthcare
professional or a facility manager after Aadhaar authentication. It is
the professional's digital identity across ABDM, and it is created on
the [HPR](hpr.md). See [M4](/docs/hiecm/v3/getting-started/glossary#m4).

## Before you start

Nothing. A glossary entry assumes no prior reading.

## What happens

Nothing happens here. This entry defines a term, it does not describe a call.

## How you know it worked

You have understood this when you can say who an HPID is issued to and where it is created.

## When it goes wrong

Expecting the number before Aadhaar authentication. NHA issues it after
that step, so anything needing an HPID cannot run first.
