# HIMS, the same system as an HMIS

## In plain words

Hospital Information Management System. It is the same thing as an
[HMIS](hmis.md), with the middle two letters swapped, and both spellings
are in common use. NHA writes HMIS. Vendors and job adverts write
either. If a document says one and your contract says the other, they
are talking about the same software.

Read [HMIS](hmis.md) for what the system is and which ABDM role it plays.

## Before you start

Nothing. A glossary entry assumes no prior reading.

## What happens

Nothing happens here. This entry defines a term, it does not describe a call.

## How you know it worked

You have understood this when you stop looking for a difference between
an HIMS and an HMIS, because there is not one.

## When it goes wrong

Treating the two spellings as two products and going looking for
separate onboarding for each. There is one system and one integration.
