# HPR, Healthcare Professionals Registry

## In plain words

HPR holds verified healthcare professionals: doctors from every system
of medicine, meaning modern medicine, dentistry, Ayurveda, Unani,
Siddha, Sowa-Rigpa and homeopathy, along with nurses and pharmacists.
Registration issues a Healthcare Professional ID, which acts as the
professional's identity across ABDM.

Enrolment is voluntary and free. It does not replace the registration a
professional already holds with their council. The councils remain the
authority, and HPR verifies against them.

HPR and the Health Facility Registry together make up the National
Healthcare Providers Registry, NHPR, which is milestone M4. Both
`hpr.abdm.gov.in` and `facility.abdm.gov.in` now redirect to
`nhpr.abdm.gov.in`.

## When it goes wrong

HPR runs on a different host and a different API version from M1 to M3, so credentials and base URLs do not carry across.

The identifier is spelled three ways across NHA's own pages: Healthcare
Professional ID, HPR ID and HPID. They are the same thing.

A facility manager is not an HPR category. It is the person who
registers a facility in the Health Facility Registry, and they use a
Healthcare Professional ID to do it. An earlier version of this entry
listed facility managers as if HPR held them, and it does not.

An earlier version also called the Healthcare Professional ID a
fourteen digit identifier. No fetched NHA page states its length, so
the claim is removed rather than repeated.
