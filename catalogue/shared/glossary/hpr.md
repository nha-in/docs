# HPR, Healthcare Professionals Registry

## In plain words

HPR holds registered doctors, nurses and facility managers. Registration
issues an HPID, a fourteen digit identifier that acts as the
professional's digital identity across ABDM.

HPR is part of M4, which is Phase 2 in this catalogue and not written.

## Before you start

Nothing. A glossary entry assumes no prior reading.

## What happens

Nothing happens here. This entry defines a term, it does not describe a call.

## How you know it worked

You have understood this when you can say what HPR is without using the acronym itself.

## When it goes wrong

HPR runs on a different host and a different API version from M1 to M3, so credentials and base URLs do not carry across.
