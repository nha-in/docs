# ABHA number

## In plain words

An ABHA number is fourteen digits, usually written as 91-1234-5678-9012.
It is issued only after a successful KYC check, most often against
Aadhaar, which is what makes it trustworthy enough to hang health records
on.

It is not the thing you route records with. That is the ABHA address.

## Before you start

Nothing. A glossary entry assumes no prior reading.

## What happens

Nothing happens here. This entry defines a term, it does not describe a call.

## How you know it worked

You have understood this when you can say what ABHA number is without using the acronym itself.

## When it goes wrong

People routinely confuse the number with the address. If the value has hyphens and only digits, it is the number.
