# UHI

Everything the UHI gateway has, in one folder.

| Folder | Holds |
| --- | --- |
| `openapi/v1/` | Three specifications, generated by `scripts/ingest-uhi.mjs`, with `journeys/` (twelve service flows). |
| `openapi/corrections/`, `openapi/.raw/` | Our recorded patches, and NHA's UHI set of 28 September 2026 stored untouched. |
| `map/` | The content map for atoms written on pages: `network.yaml`, `consultation.yaml` and `ambulance.yaml` for the notes partials under `site/docs/_notes/uhi/`, one per operation; `concepts.yaml`, `services.yaml` and `pages.yaml` for the concept, service, getting-started, test case and glossary pages. |
| `glossary/`, and one folder per atom type | The atoms. EUA and HSPA are written here; every other UHI atom is built from its page by `npm run build:sections` and carries `generated: true`. Terms every gateway shares are in `catalogue/shared/glossary/`. |

Edit a generated atom's page, never the atom. READMEs are contributor notes, never indexed.
