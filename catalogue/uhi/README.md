# UHI

Everything the UHI gateway has, in one folder.

| Folder | Holds |
| --- | --- |
| `openapi/v1/` | Three specifications, generated by `scripts/ingest-uhi.mjs`, with `journeys/` (twelve service flows). |
| `openapi/corrections/`, `openapi/.raw/` | Our recorded patches, and NHA's UHI set of 28 September 2026 stored untouched. |
| `glossary/` | EUA and HSPA, the terms UHI owns. Terms every gateway shares are in `catalogue/shared/glossary/`. |

A new atom type folder, or `map/` for atoms written on pages, appears when its first file does, laid out as in `catalogue/hiecm/`. READMEs are contributor notes, never indexed.
