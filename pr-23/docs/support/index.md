# Support

For integration-related queries, issues or technical assistance, raise a support request through the designated support channels.

## Support ticketing platform (recommended)

Submit integration-related issues, API errors, onboarding queries, certification-related concerns and implementation support requests through the designated support portal: [sandboxsupport.abdm.gov.in](https://sandboxsupport.abdm.gov.in/).

## Integration support email

Queries may also be sent to <integration.support@nha.gov.in>.

## Before you raise a request

Include the details in [what to put in a support request](/docs/pr-23/docs/hiecm/v3/troubleshooting#what-to-put-in-a-support-request), so the call you made can be traced.
