M4 test cases

The 190 cases M4 Registry Integration is tested against. They cover searching the Health Facility Registry, registering a facility in four steps, updating it and linking bridges to it, then creating a Healthcare Professional ID and registering the professional on the HPR. Each row keeps the case id the functional testing report uses, and links every API the case calls. How to read a case explains the columns and markings.

An AI coding assistant can walk these cases against your own system with the M4 Registry Integration skill.
