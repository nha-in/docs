# Other errors

Codes any exchange call can meet are recorded once, in the [Other](/docs/pr-13/docs/nhcx/v1/api/other) specification: the gateway's NHCX- codes, the standard payer codes, and the reference payer's structure and transport codes. The reference payer's other codes sit with the exchange they reject: coverage eligibility, preauthorisation, claim and insurance plan. [Reading error codes](/docs/pr-13/docs/nhcx/v1/reference/error-code-guide) explains the code spaces.

18 codes from PAYR-1003 to PAYR-1020 mean one thing on the standard payer sheet and another on the reference payer's sheet. Read the code together with its message.

## Code ranges

| Range       | What it covers                                                                                     | Examples                 |
| ----------- | -------------------------------------------------------------------------------------------------- | ------------------------ |
| `NHCX-1xxx` | The exchange, on the envelope. The message never reached the payer.                                | `NHCX-1001`, `NHCX-1002` |
| `PAYR-10xx` | Transport and bundle structure. An element, id, sequence or type is missing. Not a value problem.  | `PAYR-1001`, `PAYR-1002` |
| `PAYR-11xx` | Coverage eligibility. The policy, the beneficiary or the hospital configuration.                   | `PAYR-1101`, `PAYR-1102` |
| `PAYR-12xx` | Preauthorisation. Codes, amounts, dates, sequencing and scheme rules.                              | `PAYR-1201`, `PAYR-1202` |
| `PAYR-13xx` | Claim. The same, against the approved preauthorisation.                                            | `PAYR-1301`, `PAYR-1302` |
| `PAYR-14xx` | Insurance plan, and the scheme's outer rules. Empanelment, policy association, plan configuration. | `PAYR-1401`, `PAYR-1402` |

Every code above is recorded in the specification that owns it. The aggregated list across modules is at [error codes](/docs/pr-13/docs/nhcx/v1/reference/error-codes).
