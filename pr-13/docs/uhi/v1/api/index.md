# UHI API reference

No OpenAPI specification is published for UHI yet. The message shapes for each service are on its own page.

- [Network and protocol](/docs/pr-13/docs/uhi/v1/concepts/network-and-protocol): the search, select, init and confirm pattern every UHI service shares, and the roles on either side of it.
- [Onboarding](/docs/pr-13/docs/uhi/v1/getting-started/onboarding): registration, the signing keys and the callback URL your participant registers.
- The service pages: the fields each service adds on top of the shared pattern.
