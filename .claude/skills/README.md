# Skills

Agent skills for this repo. Claude Code auto-discovers anything here.

One folder per skill, containing `SKILL.md`:

```
.claude/skills/<skill-name>/SKILL.md
```

```markdown
---
name: skill-name
description: Use when <trigger> - <what it does>
---

Instructions here.
```

Supporting files (scripts, references) go alongside `SKILL.md` in the same folder.
