# The icons in use

Grouped by what they mean, because the question this answers is "does this subject already have a mark", not "what does `droplet` mean". Check here before choosing a new one.

Regenerate the counts by reading the repository, not by trusting this file: the icons are declared in `_category_.json` files, page front matter and the module specifications, and this page is written by hand.
