# Payment notice errors

Codes any exchange call can meet are recorded once, in the [Other](/docs/pr-14/docs/nhcx/v1/api/other) specification: the gateway's NHCX- codes, the standard payer codes, and the reference payer's structure and transport codes. The reference payer's other codes sit with the exchange they reject: coverage eligibility, preauthorisation, claim and insurance plan. [Reading error codes](/docs/pr-14/docs/nhcx/v1/reference/error-code-guide) explains the code spaces.

The Payment notice specification records no error code yet. That is a gap in the specification, not a promise that this module cannot fail.

Every code above is recorded in the specification that owns it. The aggregated list across modules is at [error codes](/docs/pr-14/docs/nhcx/v1/reference/error-codes).
